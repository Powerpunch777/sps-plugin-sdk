# Security policy

Do not report vulnerabilities, private keys, authentication tokens, customer data, or a reproducible exploit through a public GitHub Issue.

Send a minimal report to the SPS maintainer through the contact route listed on the SPS product site. Include the SDK version, affected command or module, impact, and safe reproduction steps. Remove secrets and personal data before sending anything.

The maintainer will acknowledge the report, assess impact, and coordinate a fix before publishing technical details.
