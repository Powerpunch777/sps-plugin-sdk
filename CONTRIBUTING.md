# Contributing to SPS Plugin SDK

Use GitHub Discussions for design questions, ideas, and extension workflow feedback. Use Issues only for reproducible SDK or CLI defects.

Do not include SPS Desktop logs containing personal data, API keys, Registry private keys, invitation codes, customer project files, or screenshots of private workspaces. Report a security concern through [SECURITY.md](SECURITY.md), not a public thread.

Contributions must keep the SDK independent from SPS Core, Desktop, Owner Host, user data, and private product repositories. Run `npm test` before opening a pull request.
